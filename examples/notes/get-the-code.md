# Get the code

This demo is built by one command from four Markdown files:

```
bun scaffold.ts --demo --out site --routing path
```

The drop-in is two files, `sliding-columns.js` and `sliding-columns.css`, with no dependencies. Add them to any page, wrap your note in a column, and call `SlidingColumns.init()`.

Source, docs, and the retrofit guide: <https://github.com/txmyer-dev/the-whole-stack>
